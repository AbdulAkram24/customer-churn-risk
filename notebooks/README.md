# Jupyter Notebooks

This directory contains Jupyter notebooks for exploratory data analysis and model experimentation.

## Files

- `churn_risk_analysis.ipynb` - Exploratory Data Analysis (EDA)
  - Data loading and inspection
  - Statistical summaries
  - Feature distributions
  - Correlation analysis
  - Data visualization

## Usage

Run notebooks with:
```bash
jupyter notebook
```

Then open the desired notebook in your browser.
